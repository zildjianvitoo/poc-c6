## 3. Checklist validasi manual di iPhone (urut)

Siapkan: iPhone iOS 18, kabel ke Mac, **earphone kabel**, AirPods, file lagu milikmu di app Files (mis. *A Whole New World* dari `local-songs/` — jangan di-commit).

**0. Pasang app**
- [ ] `git switch integration && git pull`, buka Xcode, Run ke iPhone (⌘R). Detail: `docs/test-reports/device-test-checklist.md` bagian 0.
- [ ] Buka Debug Settings: pastikan **CoreML stem separation** = ON, **Hit tolerance** = 80, **Allow recording without earphones** = OFF. (Ini sekaligus mengecek migrasi pengaturan lama.)

**1. Earphone wajib**
- [ ] Tanpa earphone: di layar Ready tombol **Record abu-abu** + label oranye "Plug in earphones to record."
- [ ] Colok earphone kabel: tombol Record aktif **tanpa perlu keluar layar**. Cabut lagi → nonaktif lagi.

**2. Impor & persiapan lagu (CoreML di iPhone)**
- [ ] Choose from Files → pilih lagu → trim 30–60 s → Prepare Song.
- [ ] **Catat waktu persiapan** (dari tekan Prepare sampai Ready). Target PRD < 30 s untuk 60 s audio.
- [ ] Tidak crash / tidak keluar sendiri (risiko memori: di Mac puncaknya 427 MB). Kalau mau angka: Xcode → Debug Navigator → Memory saat persiapan.
- [ ] Layar Ready menulis *"Background music was separated on your iPhone…"* (berarti CoreML dipakai, bukan cadangan).
- [ ] Tekan **Background**: dengar baik-baik — vokal asli harus jauh lebih pelan dari lagu asli; catat kalau ada suara aneh (berdesis, "berair", putus-putus di sambungan tiap ±6 s).
- [ ] Tekan **Original**: lagu asli terdengar normal.

**3. Sesi rekam dengan earphone kabel**
- [ ] Countdown 3‑2‑1 di awal, lalu piano roll jalan; balok mudah diikuti (tidak terlalu kecil-kecil).
- [ ] Nyanyi mengikuti: trail hijau saat pas, termasuk kalau kamu nyanyi **satu oktaf lebih rendah/tinggi**.
- [ ] Sengaja diam/meleset di satu segmen → TRY AGAIN → not salah merah → countdown → pre-roll (not sebelumnya **abu-abu**) → ulangi segmen.
- [ ] Lulus semua segmen → layar Export otomatis.
- [ ] Rasa delay trail vs suaramu (< 100 ms = terasa langsung).
- [ ] Baris debug "Mic …": sekitar **19–20/s** saat bernyanyi.

**4. Video hasil**
- [ ] Portrait, mirror seperti selfie, tidak ada overlay piano roll di video.
- [ ] Vokal sinkron dengan musik sepanjang klip; **tidak ada klik** di perpindahan segmen.
- [ ] Musik latar di video = versi CoreML (vokal asli pelan).
- [ ] Share & Save to Photos berhasil. Waktu export < 2× durasi klip.

**5. Tes sinkron (tes klik)**
- [ ] Debug Settings → tes klik dengan **earphone kabel** → Apply. Catat nilai latency-nya (berbeda dari nilai speaker 1 Nov).
- [ ] Ulangi sesi pendek: sinkron vokal-musik di video tetap pas.

**6. Interupsi & AirPods**
- [ ] Cabut earphone saat merekam → sesi berhenti, ditawari export sebagian.
- [ ] AirPods: banner "Wired earphones give the best sync", mic tetap mic iPhone, tes klik dengan AirPods.
- [ ] Telepon masuk / Home saat merekam → berhenti rapi (sudah lolos 1 Nov, cek ulang sekilas).

**7. Lagu demo (cadangan)**
- [ ] "Use Demo Song" masih jalan (untuk demo kalau lagu impor bermasalah).

Tulis hasil ke `docs/test-reports/device-test-2026-11-0X.md` (format sama seperti laporan 1 Nov). Untuk ❌, sertakan screenshot/screen recording.

## 4. Risiko & gap yang diketahui

- **CoreML di iPhone belum diukur**: kecepatan, memori puncak (427 MB di Mac — bisa dikurangi dengan memproses spektrum per potongan), panas.
- **Kualitas pemisahan belum didengar manusia** — hanya diukur objektif (kebocoran melodi 12%).
- **Lisensi**: Open-Unmix kode & bobot MIT, tapi dilatih di MUSDB18-HQ (dataset non-komersial) → aman untuk PoC/akademik, cek ulang sebelum produk komersial.
- **Basic Pitch (IK-06)** belum dibuat; CREPE (fallback PRD) yang dipakai dan sudah cukup di lagu uji.
- **Lagu demo Track A (IK-04/05)** ditunda sesuai keputusan "impor sendiri dulu"; demo sintetis tetap ada.
- **TK-02** (mic tetap built-in saat AirPods) dan **IK-11** (impor di iPhone) masih 🟡 sampai checklist di atas dijalankan.
- Teman tim (Ikzaz, Takin) belum mereview/menjalankan kode di branch `integration`.
